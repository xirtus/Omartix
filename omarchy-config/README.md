# Omartix

Omartix is a beautiful, modern & opinionated Linux distribution based on
Artix Linux (Runit) and Omarchy by DHH.

This directory vendors the upstream [Omarchy](https://github.com/omacom/omarchy)
source (see `.omartix-upstream` for the pinned commit). The runit/Artix
adaptation lives in the parent repository under `runit/`, `bridge/`, and
`base-install/` — this tree is kept pristine so it can be re-synced upstream
without losing Omartix changes.

Read more at [omarchy.org](https://omarchy.org).
